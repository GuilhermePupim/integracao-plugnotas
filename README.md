# Integração PlugNotas

Projeto para integração de novos colaboradores da equipe PlugNotas.

## Objetivo

Criar uma aplicação em **Node.js** com arquitetura **Produtor x Consumidor**, utilizando o **AWS SQS** como mensageria e o **MongoDB** como banco de dados.

## Tecnologias usadas

- Node.js
- MongoDB
- AWS SQS
- API ViaCEP (https://viacep.com.br)
